# Aura – Arka Plan Silme Servisi

Aura uygulamasının kıyafet fotoğraflarındaki arka planı ücretsiz, açık kaynak
`rembg` modeliyle siler ve kıyafetin etrafındaki şeffaf boşluğu kırpar.

Bu servis, Aura'nın Cloudflare Worker proxy'si tarafından çağrılır. Tek
başına bir arayüzü yoktur.
